# Reference: Visual Telemetry Dashboard & Dual-Output Event Bus

## Overview
The visual telemetry dashboard provides a dual-screen monitoring surface for an AI agent mining edges and executing strategies. The system relies on a **Dual-Output Event Bus** where the AI agent dispatches structured JSON payloads to the local FastAPI backend server (`http://localhost:8000/api/broadcast`). The server relays these payloads over WebSockets to the web UI and via HTTP/Telegram Bot API to Telegram.

## Supported Telemetry Events & Schemas

### 1. `SIGNAL_TRIGGERED`
Emitted when an entry or exit signal is generated by a live/paper trading strategy:
```json
{
  "event_type": "SIGNAL_TRIGGERED",
  "payload": {
    "time": 1773295200,
    "action": "BUY",
    "pair": "BTC/USDT",
    "price": 64250.0,
    "stop_loss": 63400.0,
    "take_profit": 65950.0,
    "annotation": "Absorption Sweep (Hurst < 0.42, Wick > 60%)",
    "reasoning_md": "**Counterparty Trap**: Breakout buyers absorbed at resistance."
  }
}
```

### 2. `CHART_MARKER`
Emitted to place entry/exit arrows or price invalidation lines on the TradingView Lightweight Charts canvas:
```json
{
  "event_type": "CHART_MARKER",
  "payload": {
    "time": 1773295200,
    "action": "BUY",
    "price": 64250.0,
    "stop_loss": 63400.0,
    "take_profit": 65950.0,
    "annotation": "Liquidity Sweep Entry"
  }
}
```

### 3. `UPSERT_WIDGET`
Emitted to render dynamic Server-Driven UI cards into the Agent Deck:
```json
{
  "event_type": "UPSERT_WIDGET",
  "payload": {
    "id": "dsr_validation_score",
    "component": "MetricCard",
    "title": "Deflated Sharpe Ratio (DSR)",
    "phase": "PHASE_4_ADVERSARIAL_AUDIT",
    "props": {
      "value": "0.964",
      "target": "> 0.950",
      "status": "PASS",
      "subtitle": "Audited across 140 trial variations"
    }
  }
}
```

## Agent Usage Instructions
- Use `python tools/ui_dispatcher.py --event <EVENT> --payload '<JSON>'` to push real-time updates during research phases.
- Ensure all chart annotations reference explicit price levels (`stop_loss`, `take_profit`) and market structure rationale.
